# 合作方 Evaluation Guidance

## 输出结构

完整 Evaluation 必须包含：

1. `公司与服务概览`；
2. `外链健康度`；
3. `对方添加我方链接——5 篇博客候选`；
4. `我方添加对方链接——1–2 篇博客 + 3 篇 AI Quick Reference`；
5. `链接放置要求`。

不得加入 Decision、Best Bilateral Placement、Missing Information 或 reply draft。
标题、章节、表头、分析和建议使用中文；专有名词、URL、provider 指标名、精确
英文 anchor 和 insertion copy 保持原样。

## 外链健康度

- 比较完整的 `milvus.io`、`zilliz.com` 和合作方根域名，不使用 FAQ 或子目录作为
  domain health benchmark。
- 分别评估公司服务、Authority、自然流量、内容相关度和外链概况。
- Moz DA、Ahrefs DR、SEMrush Authority Score 等 provider 指标不能直接等同。
- 每份 Evaluation 的 `外链健康度` 必须包含
  [`reference/domain-baseline.md`](../../reference/domain-baseline.md) 中的固定基准。
- 新的同 provider 证据只有在保留来源和 snapshot date 时才能替换旧基准。

## 对方添加我方链接

- 正好推荐 5 篇真实 Blog；优先 2025 或 2026 年内容，旧文章只有明显更相关时才用。
- 验证 URL 和发布日期，并提供 section、anchor 和句子级插入建议。
- 候选表格固定使用以下六列，名称和顺序不得改动：`优先级`、`<合作方名称> 文章`、
  `日期`、`Section / Anchor`、`句子级插入建议`、`我方目标`。其中合作方名称使用
  tracker 或官网的正式名称，例如 `Toolify AI News 文章`、`DECODE 文章`、
  `Cloudaware 文章`；不得使用泛化的 `Partner Blog URL`、`相关位置`、
  `插入建议与目标` 等替代表头。
- `Section / Anchor` 单元格必须同时写明页面中的具体 section 或段落位置，以及该
  位置已支持或可自然承载的精确英文 anchor；不得拆成两列，也不得只写其中一项。
- `句子级插入建议` 必须给出一条可直接交给编辑执行的完整英文句子，并在句子中
  明确标出将承载链接的 anchor。不得只描述“在某段补充一句”、不得写中文操作说明，
  也不得只给主题方向。
- `我方目标` 只放最终要获得外链的真实 Milvus 或 Zilliz 非 FAQ 页面，使用可点击
  URL；不得把目标 URL 混入句子级插入建议或 `Section / Anchor`。
- 目标必须是相关的非 FAQ Milvus/Zilliz 页面。
- 拒绝 homepage、product/service、company/contact、directory、partner、footer、
  sidebar 和 generic resource-list placement。

## 我方添加对方链接

- 推荐 1–2 篇 `zilliz.com/blog/` 或 `milvus.io/blog/` 文章；每篇提供 section、
  anchor 和插入建议。
- 正好推荐 3 篇 `milvus.io/ai-quick-reference/` 页面；只需 URL 和 topical-fit 说明。
- 排除 Zilliz AI FAQ，以及产品发布、功能公告、Featured collection、launch、
  announcement、promotional 或 sponsored-style Blog。

允许与禁止的库存边界见
[`reference/placement-inventory.md`](../../reference/placement-inventory.md)。

## 放置要求与 tracker 写回

- 只接受 indexable、dofollow、正文内且语义自然的 placement。
- 拒绝 sponsored、nofollow、noindex、footer、sidebar、directory、generic resource
  list 和强行离题的 placement。
- tracker row 有 Screenshot 时，只抄录截图中可见的 authority 和 organic traffic，
  按 `DA:<value> OT:<value>` 写入 `Website Stat`。
- `DA` 只是 tracker 历史简写；Evaluation 正文必须保留截图 provider 的真实指标名。
- 截图明确不可用时写 `N/A`。不得把我方 Milvus/Zilliz 基准写入合作方字段。
